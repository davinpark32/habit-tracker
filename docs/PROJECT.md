# Hopit PROJECT v1
공동개발용 프로젝트 설명서
기준일: 2026-08-19

## 문서 목적
이 문서는 Hopit을 ChatGPT와 Cursor가 같은 방향으로 개발하기 위한 프로젝트 설명서다.
개발 작업을 시작하기 전에 AI는 이 문서와 AI_RULES 문서를 우선 확인한다.

현재 단계는 실제 서비스 출시가 아니라 개발자 2명이 직접 사용하며 핵심 경험을 검증하는 프로토타입 단계다.

## 1. Hopit이란?
Hopit은 목표를 기록하고 체크하는 것에서 끝나는 앱이 아니라,
현실의 목표 달성이 가상의 펫과의 상호작용 및 성장으로 이어지게 만드는 스마트폰 중심 웹앱이다.

핵심 가설은 '해야 할 일을 체크하는 행위'보다
'내가 한 행동이 눈에 보이는 보상과 성장으로 이어지는 경험'이 지속 동기를 더 잘 만든다는 것이다.

## 2. 핵심 경험
기본 흐름:
목표 설정 → 오늘 할 일 확인 → 목표 달성 → 보상 획득 → 펫에게 직접 보상 제공 → 펫 성장

목표 완료 이후의 보상과 펫 상호작용은 Hopit의 핵심 경험이다.
단순히 XP 숫자가 자동으로 증가하는 것으로 끝내지 않는다.

2차 프로토타입에서는 사탕과 같은 보상을 획득하고,
Pokémon-Amie(파를레)처럼 플레이어가 직접 펫에게 먹여 성장시키는 방향을 검토한다.

## 3. 제품 형태와 현재 범위
- 스마트폰 사용을 우선으로 하는 웹앱으로 제작한다.
- PC에서 실행하더라도 스마트폰 화면을 기준으로 레이아웃과 조작감을 설계한다.
- 현재 프로토타입은 개발자 2명이 직접 확인하는 용도다.
- 회원가입, 결제, 운영자 기능, 대규모 서버 구조 등 실제 서비스 운영용 기능은 현재 범위가 아니다.
- 초기 디자인과 임시 그래픽은 AI가 제작해도 된다.
- 이후 친구가 제작한 실제 UI 에셋과 3D 캐릭터 목업으로 교체할 예정이다.

## 4. 2차 프로토타입 주요 개선 방향
### 오늘 페이지
목표 목록에서 해당 목표를 바로 길게 눌러(Long Press) 달성할 수 있어야 한다.

### 캘린더
각 날짜 페이지에서 해당 날짜의 목표 목록을 확인할 수 있고,
그 화면에서 바로 목표를 추가할 수 있어야 한다.

### 목표 설정
메인 홈 화면에서 크고 이해하기 쉬운 진입 요소를 통해 쉽게 목표를 설정할 수 있도록 개선한다.

### 목표 달성
완료 순간의 UI와 UX를 개선하여
달성했다는 느낌과 보상 획득이 명확하게 전달되도록 한다.

### 펫 / 보상
목표 달성 시 자동 XP 증가 대신 사탕 등의 보상을 얻고,
플레이어가 직접 펫과 상호작용하여 보상을 사용하도록 개선한다.

### 캐릭터
친구가 3D 캐릭터 목업을 제작할 예정이다.
실제 모델 형식과 3D 구현 기술은 목업 사양이 정해진 뒤 확정한다.

## 5. 현재 역할 분담
### 친구 + Cursor
- 캐릭터 3D 목업 제작
- UI 관련 피드백 전반
- UI 관련 구현

### 사용자 + ChatGPT
- 파를레 기능 사양 작성
- 목표 달성 UX 개선
- 목표 설정 관련 전반

역할은 영구 고정이 아니다.
작업 단위마다 담당자를 정할 수 있으나, 같은 기능을 동시에 수정하지 않는 것을 원칙으로 한다.

## 6. 기능 간 접점
기능 담당은 나누되 서로 연결되는 지점은 명확하게 정의한다.

예:
목표 완료 처리 → 보상 획득 → 보상 보유 → 펫에게 보상 사용 → 펫 반응 및 성장

서로 다른 사람이 작업하더라도 데이터와 동작 규칙이 맞아야 한다.

UI 담당자가 목표 카드의 외형을 변경할 때 Long Press 같은 기능 동작을 깨뜨리지 않아야 한다.
기능 담당자가 UI를 수정해야 할 경우에도 기존 디자인 작업을 불필요하게 덮어쓰지 않는다.

## 7. 프로토타입에서 우선하지 않는 것
현재 단계에서는 다음을 우선하지 않는다.
- 완벽한 코드 구조
- 대규모 확장성
- 복잡한 로그인 및 서버 시스템
- 최종 그래픽 품질

대신 다음을 우선 검증한다.
- 핵심 흐름이 실제 스마트폰에서 자연스럽게 작동하는가?
- 목표 달성이 만족스럽게 느껴지는가?
- 보상과 펫의 연결이 다시 목표를 수행하고 싶게 만드는가?

## 8. 기준 문서
제품 기획의 기준은 'Hipit 1차 프로토타입 개요서 260815'와
이후 두 개발자가 합의한 최신 피드백 및 사양이다.

기획서와 최신 합의 내용이 충돌할 경우 더 최근에 명시적으로 합의한 내용을 우선한다.
불명확한 경우 AI가 임의로 결정하지 말고 사용자에게 확인한다.
